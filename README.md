wiki-builder
description: 
Build, upgrade, and govern working wikis for projects, roles, or learning paths. Suitable for creating new wikis, upgrading legacy wikis, wiki ingestion, wiki linting, and designing multi-wiki entry points. It defaults to a working wiki skeleton consisting of CLAUDE.md + raw/ + notes/ + outputs/ + state/ + wiki/, utilizing wiki_map.md as the master navigation when multiple wikis coexist. 
Evolve the knowledge base step-by-step into a true workflow-oriented knowledge base that actively serves your tasks.

为项目、角色或学习线搭建、升级和治理工作型 wiki。适用于新建 wiki、升级旧 wiki、wiki ingest、wiki lint、多 wiki 入口设计。默认采用 `CLAUDE.md + raw/ + notes/ + outputs/ + state/ + wiki/` 的工作型 wiki 骨架，并通过 `wiki_map.md` 处理多个 wiki 并存时的总导航。
让知识库一步步长成真正能服务任务的工作流知识库。
